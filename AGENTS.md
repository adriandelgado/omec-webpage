# Project Guidelines

This repository is a SvelteKit 3 (Svelte 5) application for the OMEC website.

## Naming Convention

Use `snake_case` for variable and function names. Use `kebab-case` for filenames. Use `UPPER_SNAKE_CASE` for "global" immutable constants. Type declarations must use `PascalCase`.

## Svelte Tooling

Use the Svelte MCP already globally integrated into the agent harness; do NOT invoke it through `npx @sveltejs/mcp`.
